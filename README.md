# LevelUp

LevelUp is an RPG-style Todo Application designed for Android and Wear OS (Samsung Watch), featuring a "Solo Leveling" inspired system UI.

## Features
- Daily & Weekly Quests (Tasks)
- XP and Leveling System
- Streak tracking and milestone badges
- Firebase backend for syncing
- Wear OS companion app

## Technologies
- Framework: Flutter
- Database: Firebase (Cloud Firestore)
- Architecture: Clean Architecture / Modular Structure
